Project

Name the plan and choose display units.

1. Map & paddocks

Draw paddocks or enter acreage manually.

GeoJSON exchanges map geometry. The editable RanchAssist .ra file preserves the full grazing plan.

2. Herd demand

Set the herd and dry-matter intake assumptions.

Planning assumption: daily herd demand = head × average weight × daily dry-matter intake %. Defaults are editable examples, not universal recommendations.

3. Rotation plan

Choose how grazing days are allocated and when the plan starts.

If blank, defaults to the smallest active paddock capacity.
Rest calculation: projected rest on a repeating rotation = cycle length − that paddock's planned graze days.

4. Rotation sequence

Drag to reorder; use arrows on phones.

Unavailable paddocks are removed from the active sequence.

5. Scenario

Stress-test the plan without changing base paddock assumptions.

6. Results

Use the schedule as a temporary planning estimate.
